🚀 OPTION 1: TESTER LOCALEMENT (2 minutes)
═══════════════════════════════════════════════════════════════

📋 Prérequis:
   • Python 3.8+ installé
   • pip installé

🔧 Installation:

   1. Ouvrir un terminal dans ce dossier

   2. Installer Streamlit:
      pip install -r streamlit_requirements.txt

   3. Lancer l'app:
      streamlit run streamlit_app.py

   4. Votre navigateur s'ouvre automatiquement! 🎉

   ⏱️  Temps total: ~2 minutes


🌐 OPTION 2: DÉPLOYER EN LIGNE GRATUITEMENT
═══════════════════════════════════════════════════════════════

Streamlit Cloud = GRATUIT, ILLIMITÉ, AUCUNE CARTE BANCAIRE!

📋 Étapes:

1️⃣  CRÉER UN COMPTE GITHUB (si pas déjà fait)
    → https://github.com/signup
    → Gratuit et rapide (2 minutes)

2️⃣  CRÉER UN NOUVEAU REPOSITORY
    → Cliquer sur "+" en haut à droite
    → "New repository"
    → Nom: iso27001-dashboard
    → Public ou Private (votre choix)
    → Cliquer "Create repository"

3️⃣  UPLOADER VOS FICHIERS
    → Cliquer "uploading an existing file"
    → Glisser-déposer ces fichiers:
       • streamlit_app.py
       • streamlit_requirements.txt
    → Cliquer "Commit changes"

4️⃣  CRÉER UN COMPTE STREAMLIT CLOUD
    → https://streamlit.io/cloud
    → Cliquer "Sign up"
    → "Continue with GitHub"
    → Autoriser Streamlit

5️⃣  DÉPLOYER VOTRE APP
    → Cliquer "New app"
    → Repository: iso27001-dashboard
    → Branch: main
    → Main file: streamlit_app.py
    → Cliquer "Deploy!"

6️⃣  ATTENDRE 2-3 MINUTES... C'EST PRÊT! 🎉

Votre app est maintenant accessible 24/7 sur Internet!
URL: https://votre-app.streamlit.app

❓ DÉPANNAGE / TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

🔴 Erreur "No module named 'streamlit'":
   → pip install streamlit

🔴 L'app ne démarre pas localement:
   → Vérifier Python 3.8+: python --version
   → Réinstaller: pip install --upgrade streamlit

🔴 Erreur sur Streamlit Cloud:
   → Vérifier streamlit_requirements.txt
   → Vérifier que tous les fichiers sont sur GitHub
   → Voir les logs dans Streamlit Cloud

🔴 L'app est lente:
   → Utiliser @st.cache_data pour les données
   → Déjà implémenté dans ce code!
